# Advomind
Advomind is a cloud-based legal case management system designed to simplify and digitize the workflow of lawyers and legal staff. The system provides centralized management of clients, cases, courts, and hearings through a secure and user-friendly interface. Built using React and Firebase Firestore, AdvoMind enables real-time data handling, role-based access control, and efficient record management without the need for a traditional backend server. The project aims to replace inefficient manual processes with a scalable and organized digital solution that improves productivity, accessibility, and data security in legal operations.
